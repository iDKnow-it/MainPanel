# MainPanel — UE5 主菜单 / 主界面系统

用 UE5(5.3,纯蓝图)做的一套游戏主界面:多级菜单、开场视频、背景音乐、关卡流切换与数据表驱动的文本管理。

## 实现要点
- **多级菜单**:主界面 → 设置 / 说明 / 开始游戏,UMG 面板之间用切换动画衔接,按钮响应统一走一套自定义事件。
- **开场视频**:MediaPlayer + 媒体纹理播放片头,播完自动进入下一界面。
- **关卡流(Level Streaming)**:主菜单关卡与游戏关卡通过流关卡切换,避免整关重新加载。
- **数据表驱动文本**:文本内容放在 DataTable(结构体定义字段),界面按行读取,改文案不用动蓝图。
- **音频**:主界面 BGM 与点击音效分开管理,进入游戏时切换音乐。
