# MainPanel — UE5 主菜单与主界面系统

> 用 UE5 做的一套完整游戏主界面:多级菜单、开场视频、背景音乐、关卡流切换、数据表驱动文本。
> 玩法与界面逻辑全部由蓝图实现;仓库只包含本人产出的部分。

## 简介

| | |
|---|---|
| **项目类型** | 游戏主界面 / 主菜单系统(可直接接到任意关卡前面) |
| **引擎版本** | Unreal Engine 5.3 |
| **实现方式** | 纯蓝图(仅保留模板默认 C++ 模块,无自定义 C++ 逻辑) |
| **用到的引擎系统** | UMG 控件、MediaPlayer + 媒体纹理、Level Streaming(关卡流)、DataTable + Struct、音频 Cue |
| **仓库规模** | 蓝图与资产 25 个 + 项目配置 |
| **入口关卡** | `/Game/FirstLevel`(另一个游戏关卡为 `/Game/NextLevel`) |

## 功能流程

```
启动 → 主界面 ─┬─→ 设置界面
               ├─→ 说明界面
               └─→ 开始游戏 → 播放开场视频 → 关卡流切到游戏关卡
```

## 实现要点

- **多级菜单**:主界面 → 设置 / 说明 / 开始游戏,面板之间用切换动画衔接,按钮响应统一走一套自定义事件,新增界面不用改已有逻辑。
- **开场视频**:MediaPlayer + 媒体纹理播放片头,播完自动进入下一界面,不需要手动点击。
- **关卡流(Level Streaming)**:主菜单关卡与游戏关卡用流关卡切换,避免整关重新加载造成的黑屏与卡顿。
- **数据表驱动文本**:界面文案放在 DataTable 里(结构体定义字段),界面按行读取 —— 改文案只动数据表,不动蓝图。
- **音频分层管理**:主界面 BGM 与点击音效分开,进入游戏时切换音乐。

## 目录结构

```
MainPanel.uproject
Config/                 项目与输入配置
Content/
  FirstLevel.umap       主界面关卡(默认关卡)
  NextLevel.umap        游戏关卡
  UI/                   主界面、子界面与切换动画
  Image/                界面素材(标题、按钮、头像框等)
  LS_Mainpanel/         关卡流与开场动画资源
  Text/                 DT_Text(数据表)+ S_Text(结构体)
  Movies/               MediaPlayer、媒体纹理与视频源
  sound/ BGM/           点击音效与背景音乐
```

## 如何打开

1. 安装 **Unreal Engine 5.3**。
2. `git clone` 本仓库,双击 `MainPanel.uproject`(若提示缺少模块,C++ 模块首次编译选 Yes 即可)。
3. 本仓库不含 UE 官方模板资源,若关卡里出现缺失提示,用 UE 新建一个 **Third Person 模板** 工程,把它的
   `Content/StarterContent`、`Content/Characters` 拷进本项目的 `Content/` 下即可。
4. 打开后默认关卡为 `/Game/FirstLevel`。

## 说明

- 仓库只包含本人产出的蓝图、素材、数据表与关卡;**UE 官方模板资源未包含**(体积大且非本人作品),按上面第 3 步补齐即可打开。
- 主界面 BGM 是一个体积较大的音频文件,同样未包含,可自行替换 `Content/BGM` 下的音频。
